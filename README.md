# DronWiki — подбор дронов и комплектующих

Статический сайт-каталог whoop / tiny-whoop дронов: **HappyModel, BetaFPV, DJI**.

## Структура категорий
- **Бренды → размеры**: `#/brand/betafpv` внутри разбит по размерам (65 мм, 75 мм, 80 мм, …)
- **Размеры → бренды**: `#/size/65mm` внутри разбит по брендам
- Размеры: 65 мм, 75 мм, 80 мм, 110 мм, 120 мм, дюймовки (1"), 2", 3", DJI-размеры
- Разделы: карточка дрона (`#/drone/...`), комплектующие с фильтром по размеру (`#/components`), сравнительная таблица (`#/compare`)

## Запуск
```bash
python3 -m http.server 8000   # открыть http://localhost:8000
```
Либо просто открыть `index.html` в браузере (сайт работает без сборки, чистый HTML/CSS/JS + hash-роутинг).

## Как расширять каталог
Все данные лежат в `data/catalog.js`:
- `sizes` — категории размеров;
- `brands` — бренды;
- `drones` — модели (поле `sizes: [...]` связывает дрон с любым числом категорий);
- `components` — комплектующие (рамки, моторы, пропеллеры, батареи, FC, VTX, RX).

Добавление новой модели = один объект в массиве `drones`. Разделы по брендам/размерам строятся автоматически.

## Запуск локального сервера

```bash
cd /workspace
python3 -m http.server 8000 --bind 0.0.0.0
```

Затем откройте в браузере: **http://localhost:8000/**

Если порт 8000 занят или недоступен, можно использовать другой порт, например:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

Альтернатива без сервера — просто открыть `index.html` двойным кликом (все пути относительные).
